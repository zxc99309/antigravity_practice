# P07｜統計、探索式分析與可重現研究

> 週次 W25–W28｜學習主線：工程 × 分析 × BI｜必修 Phase。

## 目的與入口條件

**學習成果**：學會正確描述資料、提出可驗證問題、量化不確定性，不把相關性當因果。

**前置條件**：P03/P04 的可靠 Mart 可供分析；P02 SQL 已熟練。

## 需要理解的原理

- descriptive stats、mean/median、percentile、variance、skew、outlier
- missingness、selection bias、survivorship bias、sampling vs population
- confidence interval、null hypothesis、p-value、effect size、多重檢定意識
- EDA 可重現、交叉驗證 SQL 與 Pandas、分析假設與限制

## 每週教學與工作單

### W25｜研究題目與基本描述

**原理與研究**：提出「部門平均薪資差異是否主要來自組成？」問題與初步假設。

**本人實作**：在合成資料上計算平均、中位數、四分位、分布圖；用 SQL 核對。

**應交證據**：EDA notebook + 指標定義 + 基本數據表

### W26｜偏差與缺失

**原理與研究**：比較完全案例、保留 NULL、合理插補的影響；區分 MCAR/MAR/MNAR 概念。

**本人實作**：設計兩組合成資料，示範不同缺值機制如何影響結論。

**應交證據**：缺失率、敏感度分析、限制註記

### W27｜推論與相關

**原理與研究**：學信賴區間、效果量、假設、檢定前提；相關不等於因果。

**本人實作**：比較兩群差異並說明選用方法；加上圖與區間，不只報 p-value。

**應交證據**：檢定計畫、統計結果、前提與樣本限制

### W28｜可重現報告

**原理與研究**：分析如何回答業務問題，何者不能從資料推論。

**本人實作**：建立從原始固定 seed 到圖表與結論的一鍵再生方式；同儕口頭答辯。

**應交證據**：完整分析報告 + 重新執行指令 + 反思

## 階段專題

製作薪資或電商顧客分群之 EDA；至少一個研究問題有不同統計方法下的敏感度分析。正式公司薪資與真實個資不可使用。

## Acceptance Criteria（逐條勾核）

- [ ] 每張圖明確標示單位、樣本量、缺失處理及篩選。
- [ ] 用 SQL 獨立核對重要數值；Notebook 可由頭執行到尾。
- [ ] 能說明何時中位數比平均數更合適，至少一個 outlier 反例。
- [ ] 檢定包含 H0/H1、樣本/分組、檢定前提、效果量、信賴區間與限制。
- [ ] 至少一處說明混淆變數、抽樣偏差或遺失資料可能改變結論。
- [ ] 報告包含事實、解釋、建議、未知；不把 `p<0.05` 當商業重要性。

## 必須執行的故障/反例測試

- 加入高薪離群值，看 mean/median 是否改變結論。
- 讓某城市資料缺失 50%，說明與隨機缺失差別。
- 把兩個隨時間共同上升的變數畫相關圖，說明非因果。

## 導師現場追問（不可只複述 AI 答案）

- p-value 是「虛無假設成立的機率」嗎？（不是）
- 顯著差異一定代表值得採取商業行動嗎？
- 哪些情況不該以平均數代表典型顧客？

## 常見誤區與邊界

不追求製作大量圖表；先定義問題，再挑選方法，最後承認資料限制。
