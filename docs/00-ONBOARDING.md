# 00｜入學盤點、學習契約與開工條件

## 1. 初始能力盤點（先作答，不要先讓 AI 解答）

請以 60–90 分鐘完成並保留原始答案：

1. 用自己的話解釋 CSV、DataFrame、SQL Table、Primary Key、Null 的差別。
2. 對現有專案追蹤一次流程：`app.py` → `load_csv` → `clean_missing_values` → `get_groupby_summary` → `generate_markdown_report`，寫出各函式的輸入、輸出、可能例外。
3. 建立一個新的 Git Branch，修改一個不影響既有功能的小測試，用 pytest 驗證，再做 Commit。說明分支和 PR 的用途。
4. 不使用 AI，寫出「按部門統計平均薪資」的 Pandas 做法與 SQL 草稿；若 SQL 不會，坦白註記即可。
5. 回答：為何「將缺少訂單金額的資料補平均數」可能錯誤？為何相同 CSV 重跑三次可能導致重複？
6. 用繁體中文寫 300 字，敘述一張業績報表應如何界定「營收」。

## 2. 學習契約

- 建議每週 10–15 小時：原理與閱讀 2–3h、獨立實作 5–7h、測試/排錯 2–3h、檢討 1–2h。
- 採「固定核心、彈性選修」：P01–P10 為應用型核心；P11 與 P12 必須完成，但 P11 的分散式系統深度可依目標職缺調整。
- 每週一次 15–30 分鐘 Demo；學習者須能當場不靠 AI 解說一段程式和一個業務指標。
- 不過度收集個資：專案只用合成或具適當授權的公開資料。所有截圖、Log 先遮罩 token、連線字串與姓名等敏感欄位。
- 若不會，准許退回補基礎；不得跳過 SQL / 正確性直接追逐熱門框架。

## 3. 電腦與可用工具

最低配備：Python（建議 3.12）、Git、編輯器、PostgreSQL（P02 起）、Docker（P06 起）、可用的 SQL 客戶端。Windows、macOS、Linux 皆可；CLI 範例依作業系統調整。Power BI Desktop 通常需要 Windows，若不適用，用合法的替代 BI 工具完成共通能力，再補 Power BI 專項。

開始前執行：`python --version`、`git --version`、`python -m pytest -q`；檢查 `.gitignore`、是否有密鑰、README 可否重建環境。**這些指令只是建議驗證步驟，不代表此版文件已代為執行。**

## 4. 個人學習紀錄（在自己的分支／PR 中完成）

記錄：起始日期、目標職缺（DE / Analyst / BI，允許多選）、每週可用時數、使用 OS、目前最弱的三項能力、最想完成的一個業務題目、AI 使用規則同意狀態。
