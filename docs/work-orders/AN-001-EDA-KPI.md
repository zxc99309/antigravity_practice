# AN-001｜營收異常、顧客留存與統計分析

**角色**：你兼任分析師，主管看到當月淨收款較上月上升 18%，想知道這個變化是否來自新客、舊客、客單價或退款。數字為**教學情境**，不得當作已知真實結果。

## 問題與資料

使用 P03 的合成訂單、付款、退款及 customer tables；用固定 seed 做出至少 6 個月資料，刻意加入促銷日、晚到退款、一個不完整月份與少量異常值。

## 工作任務

1. 寫分析 Brief：主要問題、假設、需要的欄位、口徑與無法回答的問題。
2. 定義淨收款、客單價、訂單數、新/舊客、退款率、30 天留存率；明確主體、分母和時間。
3. 用 SQL 與 Pandas 實作相同指標，抽樣對帳；明確列出不完整月份的排除或標記策略。
4. 做 MoM 趨勢、顧客 Cohort 留存、商品組成變化與退款來源分解。
5. 提出至少兩個可檢驗假說，說明哪一項是描述關聯、哪一項需要 A/B 才能判斷因果。
6. 寫 1 頁主管摘要（結論、證據、建議、資料品質、限制）。

## 驗收

- [ ] 指標字典含 grain、時區、分母、排除項、版本、資料 Owner。
- [ ] 4 個主要數值有獨立 SQL 對帳與人工抽查紀錄。
- [ ] 圖表有標題、單位、樣本量和缺值/異常說明。
- [ ] 30 天留存不比較尚未完整成熟的 cohort。
- [ ] 證據不足時能說「無法判定原因」而不是推測為事實。
- [ ] Notebook 可重跑；報告有至少一個敏感度分析（改分母/改退款日期口徑）。

## 口頭答辯

如果 18% 的成長來自 1 個大客戶，你的建議是否改變？若本月資料只到 20 號，應如何呈現 MoM？若促銷前後變化顯著，能否直接宣稱是促銷造成？
