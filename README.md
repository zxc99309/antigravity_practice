# 📊 CSV 資料分析助手 (CSV Data Analysis Assistant)

這是一個專為 Python 與資料分析初學者設計的輕量級網頁工具。透過 **Streamlit**、**Pandas** 與 **Plotly**，不需要撰寫程式碼即可在瀏覽器中快速上傳 CSV 檔案、檢視資料健康度（缺失值統計）、計算數值統計摘要、繪製互動式圖表，並一鍵匯出成 **Markdown 分析報告**。

---

## ✨ 功能特色

1. **多編碼智慧讀取與防呆處理**：
   - 自動支援 `UTF-8`、`UTF-8-SIG`（含 BOM）與台灣常見的 Excel `CP950 / Big5` 繁體中文編碼。
   - 內建空檔案、無資料列、格式錯誤與二進位檔案（如誤把 `.xlsx` 改副檔名為 `.csv`）的友善中文錯誤提示。
2. **資料基本概況與預覽**：
   - 即時顯示總筆數 (Rows)、總欄位數 (Columns) 與總缺失值數量。
   - 可透過滑桿自由調整要預覽的前 N 筆資料。
3. **缺失值與欄位型態統計**：
   - 自動列出每個欄位的資料型態 (`dtype`)、缺失值數量、缺失比例 (`%`) 與有效筆數。
4. **數值欄位描述性統計摘要與分組樞紐分析 (GroupBy)**：
   - 自動篩選所有數值欄位，計算有效筆數、平均數、標準差、最小值、25% 分位數、中位數 (50%)、75% 分位數與最大值。
   - 支援互動式 **分組樞紐分析表 (GroupBy)**，可任選分組欄位（如「部門」）與目標數值欄位（如「月薪」），自動計算各組筆數、平均數、中位數、最大/最小值與總和，並依平均數高低排序。
5. **互動式資料清理、條件篩選與匯出**：
   - **缺失值清理**：支援「刪除含缺失值資料列 (`dropna`)」、「數值補中位數/平均數、文字補『未知』(`fillna`)」。
   - **多欄位條件篩選**：可自由挑選類別欄位（複選項目）與數值欄位（拖曳最大/最小區間滑桿）過濾出特定子群體。
   - **匯出乾淨 CSV**：可一鍵下載清理及篩選後的 CSV（採用 `utf-8-sig` 編碼，Excel 直接開啟不亂碼）。
6. **自動資料洞察摘要 (Auto Insights)**：
   - 透過本機統計規則自動偵測缺失最嚴重的欄位、高度相關（$|r| \ge 0.7$）的數值欄位配對，以及四分位距法 (IQR) 潛在離群值。
7. **Plotly 互動式圖表**：
   - **直方圖 (Histogram)**：觀察單一數值欄位的分佈與邊際盒鬚圖。
   - **盒鬚圖 (Box Plot)**：比較各分組的中位數、四分位距與離群值。
   - **散佈圖 (Scatter Plot)**：探索兩個數值欄位之間的關聯性，支援依類別欄位上色與疊加最小平方法**線性迴歸趨勢線 ($y = ax + b$)**。
   - **長條圖 (Bar Chart)**：統計類別或文字欄位各項目出現次數（前 N 名）。
   - **相關係數熱力圖 (Correlation Heatmap)**：一眼看清所有數值欄位之間的皮爾森相關係數矩陣。
8. **匯出 Markdown 分析報告**：
   - 一鍵將完整分析結果（含自動洞察摘要、基本概況、資料預覽、缺失值統計、數值摘要與分組樞紐分析表）整理成結構化的 `.md` 報告檔案，支援線上預覽原始碼與直接下載。

```text

│   ├── analyzer.py         # CSV 讀取、編碼偵測、缺失值統計與數值摘要
```

## 🚀 安裝與執行指南

### 1. 建立並啟用虛擬環境（建議）

在專案根目錄開啟終端機（PowerShell 或命令提示字元），執行：

```powershell
# 建立虛擬環境
python -m venv .venv

# 啟用虛擬環境 (Windows PowerShell)
.\.venv\Scripts\Activate.ps1
```

### 2. 安裝相依套件

```powershell
python -m pip install -r requirements.txt
```

### 3. 啟動網頁應用程式

```powershell
.\.venv\Scripts\streamlit run app.py
```

啟動後，瀏覽器會自動開啟 `http://localhost:8501`。你可以：
- 在左側欄勾選 **「使用內建範例資料 (sample.csv)」** 立即體驗所有功能。
- 或取消勾選並上傳你自己的 `.csv` 檔案。

## 💡 初學者延伸學習建議

當你熟悉這個專案的架構後，可以試著自己動手挑戰以下小功能：
1. **新增相關係數熱力圖 (Correlation Heatmap)**：在 `src/charts.py` 中使用 `df.select_dtypes(include="number").corr()` 搭配 `px.imshow()` 畫出數值欄位之間的相關係數矩陣。
2. **新增缺失值填補功能**：在 `src/analyzer.py` 中嘗試使用 `df.fillna()`，讓使用者選擇要用「平均數」、「中位數」或「特定文字」填補缺失值，並提供清理後的 CSV 下載按鈕。
